# 一台音源同时输出到多台输出端

Windows 1.6.0 起，Windows 音源可以同时连接多台输出端。

## 使用方式

1. 打开「共享声音」页，扫描局域网。
2. 在「附近的输出端」列表中，对需要的设备点「选择」。
3. 可以单选，也可以选多台。
4. 点「连接所选」。音源会同时连接全部勾选设备。

连接后：

- 每台输出端独立显示自己的 RTT 和运行状态。
- 某一台断开不会停止其他输出端。
- 共享中可在「连接详情」看到当前主输出端状态。
- 手动 IP 也可以连接；如果已勾选其他输出端，会一起连接。

## 当前实现

- 每台输出端使用独立的 `SourceClient` 连接。
- 每台输出端独立做时钟同步、UDP 发送和重连。
- 采集端目前会为每台输出端建立一路 loopback 采集；2 台输出端约等于 2 路采集开销。
- 输出端协议不需要修改，每台主机仍然只看到一台音源。

## 带宽

```text
16-bit：约 1.54 Mbps / 路
24-bit：约 2.30 Mbps / 路

2 台：约 3.1 / 4.6 Mbps
4 台：约 6.1 / 9.2 Mbps
```

建议 2–4 台，使用 5 GHz Wi-Fi；8 台会明显增加上行和 AP 空口压力。

## 延迟和同步

第一版保证“同时出声”，不保证两台输出端严格同步。

- 每台输出端有自己的网络缓冲和硬件输出延迟。
- 两台设备放在同一房间时，可能有几十到几百毫秒的延迟差，形成回声。
- 严格的多房间同步需要第二阶段：输出端上报硬件延迟，音源按设备补偿目标缓冲。

## 限制

- 当前只实现 Windows 音源多输出。
- Android 音源仍为单输出。
- 每台输出端都单独采集一次本机声音，CPU 占用随输出端数量增加。
- 输出端上限仍由主机端的 8 路音源限制决定。
